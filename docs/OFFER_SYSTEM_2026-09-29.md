## 4. Qualification copy

Use these questions before proposing a package:

1. Which recurring task consumes the most expensive human time?
2. Where does work wait for another person, tool or approval?
3. Which workflow already has usable digital data?
4. What measurable outcome would make the project worthwhile?
5. Which action must remain human-approved?
6. What source or system is the operational truth today?
7. What would break if an automation made the wrong decision?

Red flags:
- "Automate everything"
- no owner
- no source of truth
- no measurable baseline
- permission or data access unresolved
- workflow is still changing every week

## 6. Outreach opener

Subject: **Wo verliert Ihr Team heute noch Zeit zwischen Tool A und Tool B?**

Message:

Viele KMU testen bereits ChatGPT, Copilot oder einzelne Automationen. Der grössere Hebel liegt meistens nicht im nächsten Tool, sondern zwischen den Tools: Übergaben, Copy-Paste, Follow-ups, Reporting und Entscheidungen ohne saubere Datenbasis.

Wir analysieren einen konkreten Ablauf, priorisieren die wirtschaftlich sinnvollen Automationen und bauen zuerst nur den kleinsten produktiven Workflow.

Kein KI-Theater, kein "alles automatisieren". Erst Evidenz, dann Ausbau.

## 7. Evidence standard

A claim is publishable only if one of these exists:

- production measurement from a first-party source
- accepted test / QA evidence tied to exact source
- customer-approved case evidence
- durable source artifact with exact timestamp/version
- public verifiable source for factual claims

Otherwise use neutral wording:
- "implemented"
- "tested"
- "pilot"
- "designed to"
- "can"
- "intended to"

Never convert a pilot into a success story without the result evidence.
